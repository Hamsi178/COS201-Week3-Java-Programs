# COS 201 — Computer Programming I (Week 3)

This repository contains three beginner Java console programs:

1. **SimpleCalculator.java** — performs addition, subtraction, multiplication, and division on two numbers.
2. **AverageCalculator.java** — calculates the average of any number of scores entered by the user.
3. **ItemCost.java** — calculates the total cost using the unit cost multiplied by the quantity.

## Requirements
- Java Development Kit (JDK) installed.
- A terminal or command prompt.

## How to compile and run

Open a terminal in the folder containing the files.

### SimpleCalculator
```bash
javac SimpleCalculator.java
java SimpleCalculator
```

### AverageCalculator
```bash
javac AverageCalculator.java
java AverageCalculator
```

### ItemCost
```bash
javac ItemCost.java
java ItemCost
```

Each program asks the user for input and displays the result.

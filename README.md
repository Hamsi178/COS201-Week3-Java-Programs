## Week 1 - Introduction to Programming

## Week 2 - Development Environment and First Java Program
- `week02/GreetingBanner.java` is a personalised Hello World program.
- `week02/LinePrinter.java` shows the difference between `print()` and `println()`.
- `week02/CorrectedStatement.java` is a program with the missing semicolon fixed.

## Week 3 - Variables, Data Types, Expressions and Input/Output
- `week03/ArithmeticTool.java` performs four arithmetic operations on two numbers.
- `week03/GradeMeanCalc.java` finds the sum and mean of three scores and checks they are in range.
- `week03/ShoppingBill.java` works out the amount due from units and price per unit.

## Running a Program
Go into the week folder, then use the file name without `.java` for the second command:

```
javac GreetingBanner.java
java GreetingBanner
```

## Testing
Each program was compiled and run with sample input, including edge cases such as dividing by zero and scores above 100.
